VAULT - iPhone / web version
============================
Put ALL of these files on a website (free with GitHub Pages):
  index.html, sw.js, manifest.webmanifest, icon-180.png, icon-192.png, icon-512.png

Then on the iPhone:
  1. Open the website link in Safari
  2. Tap the Share button, then "Add to Home Screen", then "Add"
  3. Open Vault from the Home Screen and create a vault with a master password

Each phone/computer keeps its own vault. Passwords are never uploaded to the website.
