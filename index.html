    Bitwarden (.json / .csv)1Password (.csv)LastPassChrome / Edge / BraveFirefoxApple PasswordsGoogle PasswordsKeePass / KeePassXC (.xml / .csv)DashlaneNordPassProton PassThis vault's .txt / .csv / backup
    Where do I find the export?
    1. Chrome / Edge / Brave: Settings → Passwords (Password Manager) → Settings → Export passwords.
    2. Firefox: go to about:logins → ⋯ menu → Export Passwords.
    3. Bitwarden: Tools → Export vault → File format .json (not the encrypted one).
    4. 1Password: File → Export → choose CSV.
    5. LastPass: Advanced options → Export.
    6. Apple Passwords (Mac): Passwords app → File → Export All Passwords to File.
    7. KeePass: File → Export → KeePass XML (2.x). KeePassXC: Database → Export → CSV.
